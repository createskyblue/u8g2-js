u8g2-js · 示例导航

U8G2 单色图形库的纯 JS 移植，浏览器像素级仿真。内部示例为 ES Module、字体按需加载， 需在项目根目录起一个 live server 后打开本页（见下方说明）。

🖥️ 交互式仿真器内部

选屏、旋转、缩放、写 U8G2 代码实时预览，运行时加载任意字体（含全量中文字库）。

🇨🇳 中文字体家族对比内部

18 个字体家族，← → 方向键或选项卡切换，字体按需动态加载，720×720 像素级渲染。

🔣 图标库 · Siji内部

u8g2 图标字体浏览：Siji 图标库（github.com/stark/siji）PUA 区图标 + open_iconic 系列。

💣 Bomberman 游戏内部

Arduboy2 版《炸弹人》纯 JS 移植：128×64 像素游戏，方向键移动、放炸弹炸怪。

📈 墨水屏传感器趋势图外部

212×102 墨水屏 CO₂ / PM2.5 / 温湿度趋势仪表盘，在线演示（外部站点）。
内部示例需要本地 HTTP 服务器，在项目根目录任选其一后重新打开本页：
npx serve .　或　python -m http.server　或　VS Code 右键 index.html → Open with Live Server
